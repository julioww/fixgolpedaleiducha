# Golpe no celular — passo a passo

**Acesse o guia:** https://julioww.github.io/fixgolpedaleiducha/

Guia interativo, em português, para limpar e proteger um celular Samsung (Galaxy S20 ou Galaxy A56) depois de um golpe com app falso de "suporte".

- Um passo por tela, com botões grandes de **Voltar** e **Próximo**.
- Cada ação tem um quadrado para marcar como feita.
- O progresso fica salvo no navegador do aparelho.
- Desenhos das telas mostram onde tocar.

É uma página única (`index.html`), sem dependências, publicada com GitHub Pages.
